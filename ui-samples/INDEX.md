# 内置界面基线样例库（ui-samples）

> 单文件、零外部依赖、浏览器直接打开即用。`2a-ui-design` 阶段自动引用作为基线；任何人可随时打开对照。
> 统一规范：`lang="zh-CN"` UTF-8 viewport · `:root` tokens（hex 兜底 + oklch 渐进增强，`@supports` 块或同声明内联双写均可）· 中性灰阶 + 单一品牌蓝 · 无蓝紫渐变/紫色 · `:hover`/`:focus-visible` · 对比度 ≥ 4.5:1 · 语义标签 + aria 关联 · 后台页均为三段式（侧导航 + 顶栏 + 内容区）。

## 用法（三步）

1. **挑基线**：按下面两张表找到最接近的页面，浏览器打开看效果
2. **记引用**：在 `UI-DESIGN.md` § 0.1 基线样例引用 里声明 `pattern:` / `system:` / `deviation:`（改了什么）
3. **改造不重造**：tokens 从基线 `:root` 起手改 OKLCH 主色；布局沿用基线骨架，再叠加项目差异

规则：本库文件只是参照物，不要求项目代码复刻；禁止把基线整页粘进 UI-DESIGN.md。
